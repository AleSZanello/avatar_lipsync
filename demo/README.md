# avatar_lipsync live demo

The app behind https://lipsync.azanello.com: turn on the microphone and the
photo lip-syncs to your voice, with the rig overlay (mesh, landmarks, heat
maps) and live mouth meters.

```sh
flutter run -d chrome
```
